## Overview

For the second AUX Challenge, I was linked to a Github repo where I was shown a png of a form and told two things:
1. Build it as I saw it
2. It has to be fully accessible

## Process

I modeled my process to reflect progressive enhancement:
1. Writing the HTML
2. Checking it with the screen reader
3. Writing the CSS
4. Testing the core interactions
5. Checking with the screen reader
6. Repeat for the limited JS it required

## Key Learnings

This project emphasized the importance of building accessibility into the development process from the start, rather than treating it as an afterthought.
